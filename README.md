# Graph Neural Networks

## About the Project

This project focuses on the implementation and comparison of Graph Neural Network (GNN) architectures for node classification. It is being developed as part of the **Computational Intelligence** course at the **Faculty of Mathematics, University of Belgrade**.

The project explores three GNN architectures:

- **Graph Convolutional Network (GCN)**
- **GraphSAGE**
- **Graph Attention Network (GAT)**

The goal is to investigate how different architectures learn node representations from graph-structured data and compare their performance on node classification tasks.

## Implemented Models

- **GCN:** Learns node representations by aggregating information from neighboring nodes.
- **GraphSAGE:** Generates node embeddings by sampling and aggregating features from neighboring nodes.
- **GAT:** Uses attention mechanisms to assign different weights to neighboring nodes during aggregation.
